# Smart Sanitizing Dustbin Using IoT

## Project Overview

The Smart Sanitizing Dustbin is an IoT-based project designed to make waste disposal more hygienic and convenient. The dustbin uses an ultrasonic sensor to detect a person's hand near the bin and a servo motor to automatically open the lid.

The system helps reduce direct contact with the dustbin and improves cleanliness.

## Components Used

- Arduino Uno
- Ultrasonic Sensor
- Servo Motor
- Dustbin
- Jumper Wires
- Breadboard
- Power Supply

## Working

1. The ultrasonic sensor detects an object or hand near the dustbin.
2. The sensor sends the distance information to the Arduino Uno.
3. When a person comes near the dustbin, the Arduino processes the sensor data.
4. The servo motor automatically opens the lid.
5. After a short delay, the lid closes automatically.

## Technologies Used

## Future Scope

The project can be improved by adding features such as waste-level monitoring, automatic sanitization, IoT-based notifications and mobile monitoring.

## Conclusion

The Smart Sanitizing Dustbin provides a simple and hygienic solution for waste disposal by reducing direct contact with the dustbin. The project demonstrates the use of sensors, Arduino and automation in a practical application.
